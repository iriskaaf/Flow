# Flow

Нативный Android-клиент Xray на основе v2rayNG 2.1.8. APK в этой папке предназначен для установки на Android 7.0 и новее. Кнопка «Добавить» в разделе «Серверы» открывает импорт из буфера обмена и сканер QR-кода. Удерживайте карточку, чтобы добавить профиль в избранное или указать страну.

Переключайте вкладки горизонтальным свайпом по экрану или нижнему меню. На главной нажмите на слайдер VPN или перетащите его ручку, чтобы подключиться или отключиться.

Потяните список серверов вниз от верхнего края для проверки задержки всех профилей. Кнопка рядом с обновлением подписки проверяет её профили, а на главной пинг проверяет активный сервер и избранное. Поиск и сортировка сворачиваются при прокрутке. Кнопка между поиском и сортировкой открывает порядок подписок. То же меню доступно по долгому нажатию на заголовок подписки. Если провайдер отправляет название подписки, Flow подставит его автоматически. Название, заданное вручную, сохраняется при обновлении.

На странице «Маршрутизация по приложениям» можно пропускать через VPN все приложения, только выбранные или все кроме выбранных. Системные приложения появляются по кнопке под поиском.

## Сборка

Откройте папку `V2rayNG` в Android Studio. Сборка использует JDK 21 и Android SDK Platform 37.0 для Material 3 Expressive. Укажите путь к SDK в настройках Android Studio, в переменной `ANDROID_HOME` или в `V2rayNG/local.properties`.

```powershell
cd V2rayNG
.\gradlew.bat :app:assemblePlaystoreDebug
```

APK появится в `app/build/outputs/apk/playstore/debug/`. Сборка подписана отладочным ключом. На Windows для прогона JVM-тестов Gradle 9.4.1 может потребоваться путь без кириллицы.

Исходная версия [v2rayNG 2.1.8](https://github.com/2dust/v2rayNG/tree/2.1.8) распространяется по GPL-3.0. В проект включены [AndroidLibXrayLite v26.5.19](https://github.com/2dust/AndroidLibXrayLite/tree/v26.5.19) и библиотеки [HEV SOCKS5 Tunnel](https://github.com/heiher/hev-socks5-tunnel/tree/dfabaa9cadf8894eb8ebfa0f75b1fee331869b34) для четырёх ABI из универсального APK v2rayNG 2.1.8.

## Статус VPN в системе

Flow отправляет постоянное уведомление во время работы VPN. Переключатель «Dynamic Island» в настройках по умолчанию включён. На совместимых версиях Android 16 он разрешает запрос Live Updates со значком Flow и флагом серверного профиля. Прошивка определяет доступность и расположение системного элемента. Разрешения можно проверить в разделе «Системные уведомления».

На HyperOS 3 большой шаблон Xiaomi Super Island передаёт логотип слева и флаг справа. Для этого Xiaomi должна одобрить сценарий и пакет приложения. При наличии допуска передайте Gradle-свойства `flowXiaomiAppId` и `flowXiaomiBusiness`. Для зарегистрированной отладочной подписи можно добавить `flowXiaomiDebug=true`. В APK из этой папки этих данных нет. [Документация Xiaomi](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2132)

По умолчанию страна берётся из флага в имени профиля или из явно заданного кода страны. В расширенных настройках можно включить определение страны выхода через настроенный сервис IP-информации. Приложение делает этот запрос через локальный прокси Xray.

## HWID

Flow отправляет заголовки HWID, необходимые для Remnawave, при добавлении и обновлении HTTPS-подписок. Идентификатор стабилен для одного сервера подписки и различается между серверами. При перенаправлении за пределы исходного HTTPS-адреса по схеме, хосту или порту заголовки устройства удаляются. Переключатель «HWID для подписок» находится в расширенных настройках. [Документация Remnawave](https://docs.rw/features/hwid-device-limit/)
